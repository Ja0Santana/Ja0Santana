### 👨‍💻 About Me

Fullstack Developer with a strong Backend focus, experienced in **Java/Spring** and **TypeScript/NestJS**, as well as modern front-end development with **React, Vite, and Tailwind CSS**. I focus on building maintainable and reliable applications following **SOLID principles, software architecture best practices, REST APIs, authentication and authorization, automated testing, observability, and containerization**.

I also work with **PostgreSQL, MongoDB, Prisma, Redis, Socket.IO, BullMQ, AWS S3, Docker, Nginx, Azure, and Supabase**, with a focus on software quality, security, scalability, and cloud-based applications.
